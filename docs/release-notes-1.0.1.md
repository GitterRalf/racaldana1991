## Racal-Dana 1991 Control 1.0.1

Dieses Release ergänzt einen Installer für Windows x86 und bietet weiterhin
einen Installer für Windows x64. Der x86-Installer legt einen eigenen
Installationsordner und eigene Verknüpfungen an. Beide Ausgaben lassen sich
unter 64-Bit-Windows parallel installieren.

| Windows-Ausgabe | Installer | Qt und MinGW |
| --- | --- | --- |
| x86 (32 Bit) | RacalDana1991-Setup-1.0.1-x86.exe | Qt 5.15.19, MinGW 8.1 |
| x64 (64 Bit) | RacalDana1991-Setup-1.0.1-x64.exe | Qt 6.11.0, MinGW 13.1 |

Für GPIB wird die passende NI-488.2-Laufzeit verwendet. Das Frequenz-Zeitdiagramm nutzt Qwt 6.3.
